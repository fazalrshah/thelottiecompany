# The Lottie Company - Lottie Animation Editor

A powerful web-based tool for previewing, testing, and editing Lottie animations locally with no file size limitations. This project provides a user-friendly interface for working with Lottie animations, making it perfect for web developers and designers.

## 🌟 Features

- **Local Lottie Animation Preview**: View and test Lottie animations without any file size restrictions
- **Color Customization**: Edit and modify colors within your Lottie animations
- **Playback Controls**: Control animation speed, play/pause, and frame-by-frame navigation
- **Export Options**: Download and export your modified animations
- **Responsive Design**: Works seamlessly across different screen sizes
- **Drag & Drop Support**: Easily upload Lottie files through drag and drop interface

## 🚀 Live Demo

Visit [www.thelottiecompany.com](https://www.thelottiecompany.com) to see the tool in action.

## 💻 Usage

1. Open the HTML file in your web browser
2. Upload your Lottie animation file (JSON format)
3. Use the controls to:
   - Adjust playback speed
   - Modify colors
   - Control animation playback
   - Export your modified animation

## 🛠️ Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- Uses the following libraries:
  - Lottie (bodymovin) for animation rendering
  - CCapture.js for animation capture
  - gif.js for GIF export functionality
